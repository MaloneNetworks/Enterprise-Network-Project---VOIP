## How to read project status

- **Planned:** part of the intended design; not built yet.
- **Connected:** the device or link exists in GNS3; operation may not be verified.
- **Configured:** settings have been applied; testing may still be pending.
- **Tested:** a specific test has been run and its result recorded.
- **Verified:** the expected behavior has been demonstrated and evidence is saved.

Do not treat a diagram or proposed configuration as proof of a working feature.
